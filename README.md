# Pizza Sales SQL Analysis

This repository contains SQL queries for exploring pizza sales performance and key business metrics.

## Contents

- `SQLQuery2bi.sql` - SQL script with KPI calculations and chart requirements for pizza sales analysis

## Metrics included

- Total revenue
- Average order value
- Total pizza sold
- Total orders placed
- Average pizzas per order
- Daily and monthly order trends
- Category-wise and size-wise sales breakdown
- Best and worst pizza performers by revenue and quantity

## Purpose

This project is intended for SQL practice and business intelligence analysis of a pizza sales dataset.

## How to use

1. Open the SQL file in SQL Server Management Studio or another SQL client.
2. Update the database name if needed.
3. Run the queries to analyze sales performance.

## Notes

The script uses the database name `pizza_sales.project` and the table name `pizza_sales`.
